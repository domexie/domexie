## NarraFork

**[NarraFork](https://github.com/NarraFork)** —— 面向真实软件工程的 AI 叙述者协作平台。

它把 AI Agent 从「聊天助手」推进为能够独立思考、调用工具、跨设备协作的**叙述者（Narrator）**，参与软件从想法到交付的完整过程：

| 能力 | 说明 |
|------|------|
| 叙述者 | 可规划、可执行、可复盘的 AI Agent，而非一次性问答 |
| 多智能体协作 | 子 agent 分工探索、设计、实现与评审，像团队一样推进 |
| 技能与知识库 | 将工作流与项目经验沉淀为可复用资产 |
| 多设备执行 | 本地与远程执行器协同，跨机器、跨环境完成工作 |

> 让 AI 成为真正的工程伙伴。
